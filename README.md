Простое приложение на Python с GUI (Tkinter) для генерации случайных цитат, сохранения истории в JSON, отображения истории и фильтрации по автору и теме. Это приложение подходит для личного использования и как учебный пример работы с Tkinter и JSON.
Возможности

    Предопределённый набор цитат (текст, автор, тема).

    Кнопка «Сгенерировать цитату» — выбирает случайную цитату.

    Отображение истории сгенерированных цитат в виде списка.

    Фильтрация истории по автору и по теме.

    Сохранение и загрузка истории в/из JSON-файла.

    Проверка корректности ввода при добавлении новых цитат (пустые строки запрещены).

Требования

    Python 3.8 или новее.

    Модуль Tkinter (обычно входит в стандартную поставку Python).

    Модуль json (входит в стандартную библиотеку Python).

Установка

    Скопируйте файл приложения в отдельную папку.

    Убедитесь, что Python установлен и доступен в PATH.

    Запустите приложение


Использование

    Нажмите «Сгенерировать цитату» для получения случайной цитаты - она отобразится вверху, и запись добавится в историю.

    Дважды кликните по элементу истории, чтобы увидеть полный текст записи.

    Для добавления новой цитаты нажмите «Добавить цитату» и заполните поля (текст, автор, тема); пустые строки не допускаются.

    Чтобы сохранить историю, нажмите «Сохранить историю (JSON)» и выберите файл; для загрузки - «Загрузить историю (JSON)».

    Для фильтрации истории выберите автора или тему в выпадающих списках; нажмите «Сбросить фильтры» чтобы вернуть полный список.

Формат JSON

История сохраняется как список объектов с полями:

    text - текст цитаты

    author - автор

    topic - тема

Примеры использования:

Быстрая генерация и сохранение истории

    Шаги: запустите приложение, нажмите «Сгенерировать цитату» 3–5 раз, нажмите «Сохранить историю (JSON)» и сохраните файл как history.json.

    Ожидаемый результат: файл history.json содержит список сохранённых объектов с полями text, author, topic; приложение покажет окно подтверждения об успешном сохранении.

Добавление своей цитаты и фильтрация

    Шаги: запустите приложение, нажмите «Добавить цитату», введите текст, автора и тему (пустые поля недопустимы). После добавления снова сгенерируйте цитату или переключитесь на вкладку истории; в выпадающих списках фильтров выберите автора или тему.

    Ожидаемый результат: новая цитата появится в списке источников (и может быть сгенерирована), фильтр по указанному автору/теме покажет только подходящие записи.

Загрузка существующей истории и просмотр

    Шаги: запустите приложение, нажмите «Загрузить историю (JSON)» и выберите заранее созданный файл history.json. Дважды кликните по записи в списке истории, чтобы увидеть полный текст.

    Ожидаемый результат: история заменит текущее содержимое истории в приложении; некорректные записи (с пустыми полями) будут пропущены.

Использование для сохранения подборок по теме

    Сценарий: вы хотите собрать подборку мотивационных цитат от разных авторов.

    Шаги: добавляйте цитаты с темой «Мотивация» (через «Добавить цитату») или генерируйте и отмечайте нужные записи; затем при фильтрации выберите тему «Мотивация» и сохраните полученную подмножеству историю в JSON.

    Ожидаемый результат: экспортированный файл содержит только записи с темой «Мотивация», готовые для обмена или дальнейшего использования.

Отладка и тестирование формата JSON

    Шаги: сохраните историю в JSON и откройте файл в редакторе; убедитесь, что каждая запись имеет поля text, author, topic. Попробуйте вручную удалить одно из полей у записи и загрузить файл в приложение.

    Ожидаемый результат: приложение загрузит только корректные записи и покажет предупреждение, если ничего не было загружено.

Быстрая проверка ввода

    Сценарий: пользователь вызывает «Добавить цитату» и оставляет поле автора пустым или вводит только пробелы.

    Ожидаемый результат: приложение покажет сообщение об ошибке «Автор не может быть пустым» и не добавит такую запись — это демонстрирует валидацию ввода.
